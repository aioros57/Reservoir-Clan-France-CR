Comment Rejoindre un Clan ?

2 options simples sont à votre disposition

Option 1 : Via le serveur Discord

Cliquez sur le bouton violet Discord sur la carte du clan choisi. Vous serez directement redirigé vers leur serveur vocal/texte pour échanger avec le Chef ou l'Adjoint avant de postuler.

Option 2 : En direct dans le jeu Clash Royale avec l'ID

  1. Cliquez sur le bouton « Copier ID » sur la carte du clan (ex: #QC29VC08).
  2. Ouvrez votre jeu Clash Royale sur téléphone/tablette/PC.
  3. Allez dans l'onglet Social / Clan > Rechercher des clans.
  4. Collez l'ID avec le # et appuyez sur Rejoindre / Postuler !
